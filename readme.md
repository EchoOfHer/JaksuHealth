# 👁️ JaksuHealth - AI Retinal Disease Detection (Web Demo)

> **"Transforming the impossible into reality, one challenge at a time."**

This repository contains the Web-Demo of **JaksuHealth**, developed for the **Startup Thailand League 2026** competition. What started as an ambitious university project evolved into a fully functional prototype that pushes the boundaries of healthcare technology.

## 💡 About the Project

**What is JaksuHealth?**  
JaksuHealth (Retinal SecondSight AI) is an intelligent web-based platform designed for the automated detection of retinal diseases. It seamlessly integrates advanced Deep Learning and Computer Vision models into a user-friendly web interface to analyze retinal scans.

**Why did we build it?**  
Vision is one of our most critical senses, yet many retinal abnormalities go unnoticed until it's too late. We developed JaksuHealth to assist in medical image segmentation and precise lesion detection. By automating the screening process, we aim to provide an accessible, fast, and highly accurate tool that can help identify high-risk areas early, ultimately making proactive eye healthcare more accessible to everyone.
